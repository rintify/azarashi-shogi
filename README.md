# アザラシ将棋

青空と南極の雪氷を舞台に、立体の動物たちで遊ぶオリジナル将棋です。React 19 / TypeScript / Vite / Three.js / React Three Fiber 9 で実装しています。

## 起動

Node.js 22.12以降の対応バージョンとnpmが必要です。

```sh
npm ci
npm run dev
```

表示されたURL（通常は http://127.0.0.1:5173 ）をブラウザーで開いてください。3D表示にはWebGL 2対応のブラウザーが必要です。3Dを開始できない環境でも「マス一覧であそぶ」から操作できます。

```sh
npm test          # ルール・探索・Worker・操作のテスト
npm run typecheck # TypeScriptの型チェック
npm run build     # dist/ に本番用ファイルを生成
npm run preview   # ビルド結果をローカル確認
npm run format    # ソースの整形
```

## あそびかた

- 初期盤面は空の10×10。先手から王を自陣5段の空きマスに置き、両王が揃ったら先手から対局開始。
- 1手に、盤上の駒の移動か、ストックからの配置を1回行います。初回の王を除き、配置は自軍の駒に辺または角で接する必要があります。体全体が盤内の空きマスに収まることも必要です。
- 移動は途中の駒を飛び越え、移動先の体と1マスでも重なる全駒を丸ごと捕食します。ジェットだけは最初の駒で止まります。
- 敵味方どちらを捕食しても、非王の駒は自分のストックへ戻ります。再配置時は必ず成る前の姿です。
- 捕食した手では1回だけ、成るかどうか選べます。白→黒アザラシは不可逆。ペンギンとシャチは捕食した手で元の姿にも戻れます。
- 相手の王を捕食すると勝ち、自軍の王だけを捕食すると負け。移動・変身を合わせた1手で両王を捕食すると引き分けです。王手による手の禁止、千日手・手数制限はありません。

駒数は各プレイヤー分です。前方は所有者によって反転します。

| 駒                          |  数 | 体・移動                                                                    |
| --------------------------- | --: | --------------------------------------------------------------------------- |
| 白アザラシ → 黒アザラシ     |   6 | 1×1。白は前へ1マス、黒は周囲8方向へ1マス                                    |
| ペンギン（歩行 ⇄ ジェット） |   3 | 1×1。歩行は周囲8方向へ1マス。ジェットは前方の最初の敵味方の駒か盤端まで直進 |
| シロクマ                    |   1 | 1×1。周囲2マスの外周16マスへ跳躍。内側のマスには着地不可                    |
| シャチ（縦 ⇄ 横）           |   2 | 縦は1×2で横±1・縦±2、横は2×1で横±2・縦±1の長方形範囲                        |
| セイウチ（王）              |   1 | 2×2。横±2・縦±2の長方形範囲                                                 |

シャチは、通常の移動先で1体以上捕食した場合に回転できます。着地時の2マスのどちらを軸にするかと回転方向を選び、変形前後を合わせたL字3マスを捕食。最終的には回転後の2マスを占有します。盤外にはみ出す回転は選べません。

### 操作とガイド

- 盤上の仲間、またはストックの駒を選び、緑色の候補マスを選択します。大型駒の配置・移動では選んだマスが盤上の座標基準となり、プレビューで体全体を確認できます。
- 捕食する手は、対象・変身候補を確認して「この手を指す」で確定。シャチの各回転候補は、選ぶとL字の捕食範囲が盤に表示されます。
- 「!」は相手の次の合法な1手で捕食されうる自軍の駒です。印を選ぶと捕食可能な相手を強調します。安全を強制するルールではありません。
- ドラッグで視点回転、スクロールでズーム。盤面右上から真上表示と視点リセットを使えます。
- キーボードのアイコンから座標付きのマス一覧を開き、TabとEnterでも操作できます。
- 「新しい対局」で先後とNPCレベルを変更できます。現在の対局は置き換わります。

## NPC

| レベル | 名前     | 思考時間の上限 |
| ------ | -------- | -------------: |
| 1      | おさんぽ |          0.1秒 |
| 2      | 見習い   |          0.3秒 |
| 3      | しっかり |            1秒 |
| 4      | 達人     |            3秒 |
| 5      | 極       |           10秒 |

Web Workerで反復深化・αβ探索・局面キャッシュ・捕食の延長探索を実行します。配置、変身、味方捕食を含め、人間と同じルールエンジンで手を生成します。低難度の評価には揺らぎを加え、「極」では除去します。探索時間の上限まで必ず待つわけではなく、勝ちが見つかれば早く指します。機種によって探索できる深さは異なり、無敗を保証するものではありません。

思考中も画面操作は可能です。新規対局ではWorkerを終了し、古い局面や以前の対局への応答を破棄します。

## 構成と拡張

```text
src/game/       React非依存の型、駒定義、合法手・捕食・変身・脅威判定
src/match/      対局状態の所有、アクション履歴、保存・復元
src/ai/         難易度定義、探索、Worker通信とライフサイクル
src/components/ 操作選択の状態、ストック、説明、設定ダイアログ
src/scene/      3Dの盤面・環境・動物メッシュ・カメラ
src/App.tsx     各層の接続と画面レイアウト
```

`GameState`・`GameAction`・`ActionPreview`は直列化可能な契約です。`applyAction(state, action, expectedRevision)`は手を検証し、新しい状態を返します。描画側は独自に移動・捕食を判断しません。探索に使用する`applyPreview`は、エンジンが生成済みのプレビューだけを受け取る内部用の高速経路です。

オンライン化では、サーバーに同じルールエンジンを配置し、認証した手番プレイヤーからのアクションと局面番号を検証して状態を配信できます。現在のNPCアダプターを通信アダプターに置き換えるための境界までを用意しており、サーバー・認証・マッチングは含みません。

対局はブラウザーのlocalStorage（`azarashi-shogi.match.v1`）に、バージョンと設定・全アクションを保存します。復元時は全手をルールエンジンで再検証します。別のブラウザーや別のポートとは共有されません。保存できない環境では画面に通知します。

動物モデル・UIの動物アイコンはソース内で制作し、外部の画像・3Dモデルの取得を必要としません。フォントはGoogle Fontsを使用し、取得できない場合はシステムフォントへ切り替わります。
