# アザラシ将棋

青空と南極の雪氷を舞台に、立体の動物たちで遊ぶオリジナル将棋です。React 19 / TypeScript / Vite / Three.js / React Three Fiber 9 で実装しています。

## 起動

Node.js 22.12以降の対応バージョンとnpmが必要です。

```sh
npm ci
npm run dev
```

表示されたURL（通常は http://127.0.0.1:5173 ）をブラウザーで開いてください。3D表示にはWebGL 2対応のブラウザーが必要です。3Dを開始できない環境でも「マス一覧であそぶ」から操作できます。

```sh
npm test          # ルール・探索・Worker・操作のテスト
npm run typecheck # TypeScriptの型チェック
npm run build     # dist/ に本番用ファイルを生成
npm run preview   # ビルド結果をローカル確認
npm run format    # ソースの整形
```

## あそびかた

- 盤面は10×10。2×2の王が先手E2–F1・後手E10–F9（両者の手前中央）に配置済みで始まり、先手から通常の1手を指します。
- 1手に、盤上の駒の移動か、ストックからの配置を1回行います。配置は自軍の駒に辺または角で接する必要があります。体全体が盤内の空きマスに収まることも必要です。
- 移動は途中の駒を飛び越え、移動先の体と1マスでも重なる全駒を丸ごと捕食します。ジェットだけは最初の駒で止まります。
- 敵味方どちらを捕食しても、非王の駒は自分のストックへ戻ります。再配置時は必ず成る前の姿です。
- 捕食した手では1回だけ、成るかどうか選べます。白→黒アザラシは不可逆。ペンギンとシャチは捕食した手で元の姿にも戻れます。
- 相手の王を捕食すると勝ち、自軍の王だけを捕食すると負け。移動・変身を合わせた1手で両王を捕食すると引き分けです。王手による手の禁止、千日手・手数制限はありません。

駒数は各プレイヤー分です。前方は所有者によって反転します。

ジェットペンギンは成るときに上下左右から向きを選び、その向きを保持して直進します。捕食して歩行に戻ると向きを解除し、再び成る際に選び直せます。以前の棋譜で向きが未指定の場合は従来どおり所有者の前方を使います。

| 駒                          |  数 | 体・移動                                                                    |
| --------------------------- | --: | --------------------------------------------------------------------------- |
| 白アザラシ → 黒アザラシ     |   6 | 1×1。白は前へ1マス、黒は周囲8方向へ1マス                                    |
| ペンギン（歩行 ⇄ ジェット） |   3 | 1×1。歩行は周囲8方向へ1マス。ジェットに成るとき4方向から向きを選び、その向きの最初の敵味方の駒か盤端まで直進 |
| シロクマ                    |   1 | 1×1。周囲2マスの外周16マスへ跳躍。内側のマスには着地不可                    |
| シャチ（縦 ⇄ 横）           |   2 | 縦は1×2で横±1・縦±2、横は2×1で横±2・縦±1の長方形範囲                        |
| セイウチ（王）              |   1 | 2×2。横±2・縦±2の長方形範囲                                                 |

シャチは、通常の移動先で1体以上捕食した場合に回転できます。最初の着地点で捕食したマスを回転後も最低1つ踏む候補から、軸と回転方向を選びます。回転で初めて捕食する駒だけではこの条件を満たしません。変形前後を合わせたL字3マスを捕食。最終的には回転後の2マスを占有します。盤外にはみ出す回転は選べません。

### 操作とガイド

- 盤上の仲間、またはストックの駒を選ぶと、移動・配置後に体が重なるマス全体を薄い水色で表示します。青い印は行き先の基準マスです。移動中も着地点の占有マスを表示します。大型駒の配置・移動では選んだマスが盤上の座標基準となり、プレビューで体全体を確認できます。
- 変身の選択肢がある捕食では、駒が移動先の上空に進んで待機し、ポップアップで姿を比較します。背景パネルのない「成る」「そのまま」ボタンで確定。白アザラシは移動範囲が広がるだけなので自動で黒アザラシになり、成りの確認は出しません（自軍王の捕食の確認は残します）。変身は空中のきらめきとともに行い、その後に着地します。取り消し時も空中から元のマスへ戻ります。選択肢のない捕食は即実行（自軍王の捕食だけは敗北確認）。シャチは回転で届く範囲も通常の範囲と同じ薄い水色で表示します。形のボタンを選ぶと、空中のシャチが実際の向き・位置へ滑らかに切り替わり、そのL字の捕食範囲を強調します。確定後はプレビュー位置からきらめきとともに着地します。
- 「!」は相手の次の合法な1手で捕食されうる自軍の駒です。印を選ぶと捕食可能な相手を強調します。安全を強制するルールではありません。
- 台座のない動物が雪上に立ち、体の青・橙の印で敵味方を区別します。ジェットペンギンは腹ばいで頭・くちばしを進行方向へ向けます。
- UIの開閉・切り替えはフェードと小さな弾み、手番・ストック・メニューアイコンはクロスフェード。閉じる演出中の操作は無効になり、設定を閉じ終わるまでNPCは待ちます。移動ガイド・危険点・配置プレビューも滑らかに切り替わります。
- 3Dの氷原を全画面表示し、HUDを重ねます。画面は `100dvh` 内に収まり、縦横スクロールしません。横向き・safe-areaにも対応します。
- 持ち駒は下部の高さ44pxのバーに集約。タップしたときだけ選択欄を重ねて開き、駒を選ぶと自動で閉じます。欄の開閉や駒の選択では盤面の縮尺・位置を変えません。
- 画面サイズに合わせて盤面を配置します。右上の「真上／3D」で視点を切り替えます。タップ中の意図しない回転を防ぐため、ドラッグでカメラは回りません。
- 配置、滑走、跳躍、捕食、回転を再生します。演出中は追加入力とNPCの次手を止め、王の捕食演出が終わってから結果を出します。
- シャチは波と泡を残して泳ぎ、ジェットペンギンは青白い噴射・航跡とともに加速します。王は大きく弾んで着地し、体の沈み込みと雪ぼこりを出します。捕食時は「ガブッ」という噛みつき音、王の着地は低い衝撃音を同期して鳴らします。盤の数字・英字は表示しません。
- 移動・配置後に、その駒か自分の王が相手の次の1手で捕食されうる着地点は、点・マスの塗り・枠を赤で表示します。捕食後の局面で判定するため、脅威元を食べて安全になる手は青です。シャチのL字捕食、ジェットの停止位置、成り後の形も含みます。変身を選ぶ前は通常の着地、選択中は選んだ候補の危険度を表示します。王手での決着や危険手の禁止はありません。
- ×、同じ駒の再選択、Escapeで選択を解除できます。結果画面の「盤面を見る」で終局の盤面も確認できます。
- 設定・ルールは右上から開き、表示中はNPCを停止します。長い説明はダイアログ内だけでスクロールできます。
- マス目アイコンで座標操作に切り替えます。Tabで盤面に入り、矢印キーとEnterで操作できます。後手なら盤面が自分向きに反転します。
- 効果音のON/OFFを保存します。端末の「視差効果を減らす」設定にも対応します。
- 「新しい対局」で先後とNPCレベルを変更できます。それまでの指し手はリプレイ一覧に残ります。

## 保存とリプレイ

各棋譜の「解説用」から、LLMに読み込ませられるUTF-8のテキストをダウンロードできます。確定ルール、座標の読み方、初期局面、全着手の移動・変身・敵味方の捕食・ストック、最終局面と結果を含みます。狙いや形勢評価は生成せず、保存された指し手をルールエンジンで再現した事実を書き出します。

右上のフィルムアイコンから対局一覧を開きます。人間対AI・AI対AIとも、一手ごとにこのブラウザーへ自動保存。終局前の棋譜も、新しい対局を始めたあとも見返せます。途中局面からの分岐や編集は行いません。

「再生」で初期局面から3Dの演出・効果音付きで再生します。下部のバーで再生／停止、一手戻し・一手送り、最初・最後への移動、スライダーでの局面選択、0.5倍／1倍／2倍の速度を操作できます。停止時は再生中の一手を見せてから止まります。×で現在の対局へ戻り、対局は見返す前の局面から再開します。リプレイ中はNPCの思考・盤面への指し手入力を止め、現在の棋譜を変更しません。

一覧のダウンロードボタンで棋譜をJSONファイルへ保存でき、「棋譜ファイルを読み込む」で復元できます。読み込み時はルールバージョンと全指し手を検証します。端末間で移す場合はこのファイルを使ってください。ブラウザーのデータ削除で端末内の保存は消えるため、残したい棋譜はファイルでも保存してください。

## AI同士の観戦

右上の「新しい対局」から「AI vs AI」を選択すると、王を初期配置した局面から両AIが自動で対局します。先手・後手のレベルを個別に設定でき、下部の「一時停止／再開」「1手」で進行を操作できます。思考中の停止はWorkerを終了し、再開時に現在の局面から考え直します。再生中の一手は最後まで見せてから停止します。

観戦モード・両AIのレベルも対局履歴と一緒に保存・復元します。AIが変身を選んだ場合は選択ポップアップを出さず、上空への移動・変身・着地まで自動で再生します。

## NPC

| レベル | 名前     | 思考時間の上限 |
| ------ | -------- | -------------: |
| 1      | おさんぽ |          0.1秒 |
| 2      | 見習い   |          0.3秒 |
| 3      | しっかり |            1秒 |
| 4      | 達人     |            3秒 |
| 5      | 極       |           10秒 |

Web Workerで反復深化・αβ探索・局面キャッシュ・捕食の延長探索を実行します。配置、変身、味方捕食を含め、人間と同じルールエンジンで手を生成します。低難度の評価には揺らぎを加え、「極」では除去します。探索時間の上限まで必ず待つわけではなく、勝ちが見つかれば早く指します。機種によって探索できる深さは異なり、無敗を保証するものではありません。

思考中も画面操作は可能です。新規対局ではWorkerを終了し、古い局面や以前の対局への応答を破棄します。

対局ごとに新しい乱数シードを生成して棋譜へ保存します。同じ局面でも対局が違えば評価の揺らぎや同順位の探索順が変わり、固定した序盤の繰り返しを避けます。「極」は評価に乱数を加えず、同順位の手の探索順だけ変化させます。リプレイは探索をやり直さず、保存した指し手をそのまま再現します。

## 構成と拡張

```text
src/game/       React非依存の型、駒定義、合法手・捕食・変身・脅威判定
src/match/      対局状態の所有、アクション履歴、棋譜一覧の保存・復元・リプレイ
src/ai/         難易度定義、探索、Worker通信とライフサイクル
src/components/ 操作選択の状態、ストック、説明、設定ダイアログ
src/presentation/ 確定済みの手の時間軸・再生・効果音・表示領域
src/scene/      3Dの盤面・環境・動物メッシュ・カメラ
src/shared/     対局の乱数生成・シードからの再現可能な乱数
src/App.tsx     各層の接続と画面レイアウト
```

`GameState`・`GameAction`・`ActionPreview`は直列化可能な契約です。`applyAction(state, action, expectedRevision)`は手を検証し、新しい状態を返します。描画側は独自に移動・捕食を判断しません。探索に使用する`applyPreview`は、エンジンが生成済みのプレビューだけを受け取る内部用の高速経路です。

オンライン化では、サーバーに同じルールエンジンを配置し、認証した手番プレイヤーからのアクションと局面番号を検証して状態を配信できます。現在のNPCアダプターを通信アダプターに置き換えるための境界までを用意しており、サーバー・認証・マッチングは含みません。

対局はブラウザーのlocalStorage（`azarashi-shogi.match.v2`）に、バージョンと設定・全アクションを保存します。復元時は全手をルールエンジンで再検証します。旧ルールの棋譜（`azarashi-shogi.match.v1`）は上書きせず残し、対戦モード・先後・難易度を引き継いで新ルールで開始します。別のブラウザーや別のポートとは共有されません。保存できない環境では画面に通知します。

リプレイ一覧は別の`azarashi-shogi.replays.v1`に対局ID・開始時刻・乱数シードと棋譜を保持します。現在のv2棋譜には不足するメタデータだけ補い、既存の指し手をそのまま引き継ぎます。保存容量不足でもメモリー内の棋譜はダウンロードでき、読み込み不能の既存ライブラリーを上書きしません。

動物モデル・UIの動物アイコンはソース内で制作し、外部の画像・3Dモデルの取得を必要としません。UIは端末の丸ゴシック・システムフォントを使用します。
